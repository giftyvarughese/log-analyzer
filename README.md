# Log Analyzer

## Overview
This project is a Python-based Log Analyzer that reads a log file, counts successful and failed login attempts, and generates a simple security report.

## Features
- Read log files
- Count successful logins
- Count failed logins
- Calculate failed login percentage
- Detect suspicious login activity
- Handle missing files using exception handling

## Technologies Used
- Python
- File Handling
- Exception Handling

## How to Run

1. Run the program.
2. Enter the log file name.
3. View the generated analysis report.

## Example Output

```
========== LOG ANALYSIS REPORT ==========
Total Log Entries : 5
Successful Logins : 3
Failed Logins     : 2
Failed Login Percentage : 40.0%

 No suspicious activity detected.
```
